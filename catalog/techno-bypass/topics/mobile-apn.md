# Мобильные APN

Исследование альтернативных точек доступа (APN) как канала выживания
туннелей при блокировках. Одна из самых насыщенных тем канала
(май–июль 2026). Всё — **Research**, если не указано иное: это наблюдения
форвардов и авторов, не верифицированные систематически.

## Идея

Уход со стандартного шлюза (`internet`) на корпоративные (b2b), телематические
(m2m) и архивные (WAP) APN: на них другие профили фильтрации, потому что
через них работает бизнес-трафик (банкоматы, кассы, датчики). Скорость
спец-точек умышленно порезана (≈5–10 Мбит), ценность — проходимость
туннелей, а не скорость. Это «план Б» на случай жёстких отключений —
Source: #1040, #1041.

## Универсальный конструктор

`b2b.<оператор>.<регион>.ru` (например `b2b.tele2.spb.ru`,
`b2b.tele2.nn.ru`, `b2b.tele2.chel.ru`); федеральные fallback:
`b2b.tele2.ru`, `corp.tele2.ru`; Мегафон: `b2b.megafon.ru`,
`m2m.megafon.ru`; Билайн: `b2b.beeline.ru`, `static.beeline.ru`;
МТС: `b2b.mts.ru`, `m2m.mts.ru`, `m2m-spb.mts.ru`; WAP-набор:
`wap.tele2.ru` / `wap.megafon.ru` / `wap.beeline.ru` / `wap.mts.ru`.
Правила настройки: тип APN строго `default,supl` (без пробелов),
пустые прокси/порт/логин/пароль, переключение через авиарежим —
Source: #886, #1040 (форварды Ivan Babich).

## Наблюдения (Observed для авторов форвардов)

- Смена APN «оживляет» конфиги подписок, не работающие на дефолтном APN
  (пример: Tele2 + `mobile.skylink.ru` — работает большинство конфигов
  V2RayNG против одного на дефолте) — Source: #1043.
- Бесплатный обход белых списков МТС через WAP-APN (только МТС) —
  Source: #871 (форвард РКП).
- На спец-точках скорость режется до 5–10 Мбит — Source: #1041.
