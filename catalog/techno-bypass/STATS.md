## Методика

1. `python3 tools/parse_telegram_export.py --out <workdir> messages*.html`
   — парсер (stdlib, без зависимостей; сортировка по id, дедупликация,
   ISO-даты, классификация ссылок, поиск чувствительных паттернов).
2. Ручная куризация: чтение дайджеста (все содержательные сообщения),
   кластеризация тем, написание каталога.
3. Сырой dataset (messages.json/links.json) содержит текст канала — в git
   не попадает; воспроизводится прогоном парсера на экспорте.

Повторный прогон на новом экспорте даёт свежий dataset для сверки; файлы
каталога парсер не перезаписывает (см. README каталога).
