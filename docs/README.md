# Каталог статей / Knowledge articles

Это навигационная страница **публичных материалов `docs/`**. Она не заменяет первоисточники и не делает каждое утверждение «проверенным»: откройте статью и прочитайте её **статус, область применимости и дату последней проверки**.

**Статусы:** `Confirmed` — проверено в обозначенном объёме; `Observed` — конкретное практическое наблюдение; `Research` — исследование/гипотеза или неполная проверка; `Historical` — сведения об исторической реализации. Одна статья может включать несколько статусов.
