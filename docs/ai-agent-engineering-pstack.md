## Какие практики заимствуем

| Источник | Локальная польза | Куда перенесено |
| --- | --- | --- |
| `unslop` + `technical-writing` | Конкретная русская техническая документация без ИИ-штампов и придуманных метрик | Общий инженерный стандарт |
| `prove-it-works`, `test-behavior-not-implementation`, `create-verification-skill` | Проверка реального пользовательского пути, не только сборки и mock | KAS, link-generators, Router Emulator |
| `blast-radius`, `interrogate`, `correct` | Проверка косвенных последствий изменений, независимое воспроизведение дефекта, исправление повторяющихся ошибок агентов | Общий стандарт, KAS |
| `make-operations-idempotent` | Перезапуск install/update/uninstall, rollback, рестарт роутера | KAS, NVR |
| `benchmark-checklist` | Достоверные метрики RSS/CPU/скорости/ошибок | WDTT Suite |
| `show-me-your-work` | Журнал решений и проверяемых ссылок для сложных PR | Общий стандарт |
| `statechart`, `create-formal-verification-skill` | Модель переходов состояний и инвариантов для особо рискованных сценариев | Backlog: оценить узкий PoC перед внедрением |

**Канонические правила:** [saymer-alt/saymer-alt, PR #11](https://github.com/saymer-alt/saymer-alt/pull/11). Эта статья не является отдельной «конституцией», не описывает реализованные тесты и не подменяет код владельческих проектов.

## Непереносимые части

Не копировать все 58 навыков, завязанные на Cursor Task, названия моделей, Slack/Tailscale, отдельные модели или файлы `.cursor` без необходимости. Не принимать дословно запрет любых комментариев, непрерывную автономность агентов или запреты на русскую типографику. При несовместимости действуют локальные права, безопасность, owner GO, Proof Before Build и минимальное обоснованное изменение.

## Порядок пересмотра

При обновлениях upstream сравнить diff навыка с местными правилами, установить реальную пользу, измеримую проверку, цену сопровождения и границы безопасности. Дальнейший перенос делать отдельным PR; отсутствие изменения тоже допустимо. **Новые версии Pstack не являются основанием для автоматического переписывания AGENTS.md или CI.**
